# Brand and showcase assets

- Runtime brand assets live in [`public/branding`](../../public/branding): `fitlife-mark.svg` is the compact symbol and `fitlife-logo.svg` is the horizontal README wordmark.
- [`public/favicon.svg`](../../public/favicon.svg) uses the same mark at a browser-friendly small size.
- Real product captures live in [`docs/screenshots`](../screenshots) and are embedded directly in the repository README.
- [`public/branding/fitlife-preview.png`](../../public/branding/fitlife-preview.png) is the 1200 × 630 Open Graph/Twitter preview assembled from real Home, Workout Session, and Progress captures.

The social preview is referenced with an absolute production URL in `index.html` so link crawlers can retrieve it. Future updates must continue using real product captures rather than imagined or AI-generated application screens.
